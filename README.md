# Portafolio Técnico

Repositorio con mis proyectos en tres áreas: Mecatrónica, Ciencia de Datos y Visión Artificial.

## Índice

- [Mecatrónica](mecatronica/) — control de sistemas, robótica con ROS y firmware embebido
- [Ciencia de Datos](ciencia-de-datos/) — EDA y estadística, machine learning y deep learning
- [Visión Artificial](vision-artificial/) — procesamiento de imágenes, detección de objetos (YOLO) y segmentación semántica

## Tecnologías

ROS · Arduino / STM32 · Python · Scikit-learn · PyTorch · OpenCV · YOLO

## Configuración del entorno

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # Linux / Mac
pip install -r requirements.txt   # dentro de la carpeta de cada proyecto
```
